# 生日快樂互動網站

這是一個單檔案互動式生日賀卡網站（完整內嵌圖片與動畫）。

## 如何啟用 GitHub Pages 變成網站

1. 將以下提供的 `index.html` 上傳到這個 repository 的根目錄（覆蓋或新增）
2. 前往 **Settings** → **Pages**
3. 在 Source 選擇 **Deploy from a branch**
4. Branch 選 `main`，Folder 選 `/ (root)`
5. 按 Save
6. 等待 1-2 分鐘後，網站就會上線：
   **https://56fbyv9g27-code.github.io/happy-birthday/**

文件已經準備好，直接上傳即可。
